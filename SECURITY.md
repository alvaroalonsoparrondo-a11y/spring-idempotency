# Security Policy

## Supported Versions

Security fixes are made on `main` and shipped with the next release.

| Version | Supported |
| ------- | --------- |
| latest release and `main` | :white_check_mark: |
| older releases | :x: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Report them privately through
[GitHub Security Advisories](https://github.com/dmitriy-iliyov/spring-idempotency/security/advisories/new).

### What to include

* Description of the vulnerability and its potential impact
* Steps to reproduce (a proof of concept if possible)
* Affected service (`ride-service`, `receipt-service`, `ride-simulator`) or infrastructure file
* Version or commit, Java version, how the services were deployed

### What to expect

* An acknowledgement within 3 working days
* An assessment and, if the report is confirmed, a fix plan within 10 working days
* Credit in the release notes, unless you prefer to stay anonymous
